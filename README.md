# Insurance Claim Prediction - Machine Learning Web App

## Project Overview

This project is a Machine Learning web application that predicts insurance claim outcomes based on customer/insurance information.

The trained Machine Learning model is integrated with a **Flask** web application so that users can enter input values and receive a prediction through a simple web interface.

## Objectives

- Analyze insurance-related data.
- Prepare the data for Machine Learning.
- Train a predictive Machine Learning model.
- Save the trained model for reuse.
- Integrate the model with Flask.
- Provide predictions through a web application.

## Installation

Clone the repository:

```bash
git clone https://github.com/aayushtalaviya367-wq/insurance-claim-prediction-ml.git
```

Move into the project directory:

```bash
cd insurance-claim-prediction-ml
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

Start the Flask application:

```bash
python app.py
```

After starting the application, open the local URL shown in the terminal, usually:

```text
http://127.0.0.1:5000/
```

## Model

The trained Machine Learning model is stored in:

```text
model.pkl
```

The Flask application loads this saved model and uses it to generate predictions from user-provided inputs.

## Dataset

The project uses `insurance3r2.csv` as the dataset for the Machine Learning workflow.

The dataset is used for preparing the input features and training the predictive model.

## Application

The Flask web application provides an interface where users can enter the required insurance-related information and obtain a prediction from the trained model.
